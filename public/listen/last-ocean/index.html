01 /

项目介绍

About the project

Last Ocean 是一次围绕“海洋记忆与未来生命”展开的电子音乐创作实践，起点来自上海科技馆投稿项目的构思。

我想象一种不再依赖单一身体的未来生命：意识像水一样流动，可以聚集、分散，并在某个瞬间接触到关于海洋的模糊记忆。那些记忆可能以声音、光线、残片与感知的形式重新浮现，带来一种遥远、梦幻，又似曾相识的体验。

音乐从 Suno 生成的分轨素材起步。我选取其中可用的片段，在 Ableton 中重新采切、组合与编排，再加入 Codex 辅助构建的局部段落、Wavestate 的合成器录音、FANTOM-07 的钢琴声音，以及其他过渡音效，逐步建立自己的结构和情绪走向。

目前，项目已经形成能够完整试听的阶段版本。接下来，希望在这份声音基础上，继续探索抽象影像、声音事件与视觉变化之间的联系。

02 /

创作概念

Origin & memory

在前期构思中，我曾用“海的遗存馆”和“蓝色遗存馆”来描述这个空间。

这里的“馆”是一种保存和触发感知的容器。一段声音、一束漂浮的光，或者一次突然中断的节奏，都可能成为进入记忆的入口。

如果意识可以像水一样流动，
记忆是否也可以在不同个体、不同载体之间迁移？

我感兴趣的是：当生命形态发生变化，人们会怎样重新感知“起源”？这些想象为创作提供了三个方向：

起源与残留

遥远的经验如何以不完整的片段被保留下来。

流动与分布

意识如何聚集、分散，并重新建立联系。

个体与群体

一个细小的声音，如何与更大的声场和整体运动发生关系。

这些是作品的艺术设想，也构成了后续声音与视觉探索的出发点。

这次创作想解决什么

最初的分轨提供了一些可以继续发展的声音和氛围，但我希望加强音乐中的细节、起伏和主线，也希望出现一些能够被视觉识别和回应的声音事件。

  1. 重新安排素材，形成自己的整体结构。
  2. 通过剪辑、停顿和局部变化，增加时间上的细节。
  3. 使用硬件合成器录音，补充个人的音色选择与情绪表达。
  4. 关注段落能量和声音事件，为后续音画创作保留线索。

04 /

创作流程

Inside the sound

从声音方向、素材选择到硬件录音与手工剪辑，在反复试听中建立自己的结构。展开各步骤，查看具体过程。

01从概念建立声音方向

首先确定想要接近的感受：遥远、流动、模糊，并带有未来生命与意识的想象。

这些感受成为筛选材料的依据。我会考虑一个声音是否适合进入这个世界，以及它可以承担怎样的作用：建立空间、推动节奏、制造中断，或者补充情绪。

02筛选与重组生成分轨

制作起点是已有的 Suno 分轨。我从中挑选能够继续使用的材料，再根据自己的想法重新组织。

这个过程涉及持续的选择：保留哪些声音，使用多长，放在哪里，以及它们应该与什么内容连接。原有材料也在新的结构中获得了不同的作用。

03在 Ableton 中建立段落关系

我通过剪切、移动和重新组合，逐步调整材料出现的位置与持续时间。

这一阶段最关注的是整体推进：什么时候继续积累，什么时候下降，哪里需要空出来，哪里需要新的声音进入。作品的结构在反复试听和修改中逐渐形成。

04使用 Codex 辅助构建局部段落

制作过程中，我使用 Codex 辅助处理部分工程内容，并构建局部声音段落。其中，中段加入了一段带有偏微分音听感的材料，为音乐带来与前后不同的状态。

我负责提出声音目标、试听和选择，再继续修改。这样的协作让一些想法能够较快变成可听、可调整的材料。

这里的“偏微分音”描述的是声音方向，具体音高偏移与调律参数尚未整理。

05使用 Wavestate 补充情绪

在现有材料基础上，我录制了 Wavestate 的声音，为作品补充情绪层次。

这一部分从实际声音出发：演奏、试听、调整，再判断它与当前段落是否合适。硬件录音也让我的音色偏好进一步进入作品。

06使用 FANTOM-07 调整后段钢琴

后段加入并调整了 FANTOM-07 的钢琴声音，继续修改局部编配。

钢琴与电子声音材料放在一起，为后段提供了另一种触感和表达方式。它的具体位置与段落作用，可以在最终音频确定后进一步记录。

07制作卡碟式切片与过渡

我通过剪去部分音频、留下间隙和调整切片位置，制作了多处卡顿、跳切式的效果，也使用了其他音乐材料中的过渡音效。

这一过程让我开始注意时间的细部：声音在哪里被切断，空白持续多久，下一段如何接上，都会改变听感。

这些断续的声音，也为“记忆残片”和“感知中断”的概念提供了可以继续发展的方向。

08完整试听与反复修改

不同来源的材料进入同一工程后，我继续通过完整试听调整编排。

目前最明确的阶段感受，是作品已经形成了让我满意的流畅感和整体气质。虽然还有需要精修的地方，但它已经让我愿意继续完成和展示。

05 /

音画结合

Future experiments

目前完成的工作主要集中在音乐部分。视觉表现与交互机制仍处于探索阶段。

后续可以从音乐中选择少量清晰的线索，开展对应实验：

声音线索可探索的视觉变化
氛围层的进入与退出空间显现、遮蔽和景深变化
声音密度与能量变化群体聚散、运动速度和画面复杂度
卡碟、断点与短暂空白跳切、残影和连续性的中断
中段音高、音色状态改变形态偏移或空间形变
后段钢琴与合成器的情绪变化光线、尺度和运动方式变化

这些关系需要通过实际试听与视觉实验继续筛选。

06 /

阶段复盘

Notes & reflections

已经取得的进展

这次制作让我把几种方法放进了同一个作品：从生成分轨中筛选材料，在 Ableton 中重新组织结构，通过 Codex 辅助加入局部内容，再使用硬件录音和手工剪辑继续塑造声音。

对我而言，有价值的进展在于能够根据自己的听感采取具体行动。觉得某处缺少情绪，就尝试补录；觉得一段太平，就改变时间关系；发现值得保留的声音，就让它进入新的结构。

最终形成的阶段版本虽然还不够精细，但整体已经让我觉得流畅，也有自己喜欢的气质。这种完成感让我愿意继续深入制作。

仍需推进的内容

  • 检查作品是否具有足够清晰、能够贯穿不同段落的主线。
  • 继续整理局部切片与过渡，判断哪些变化有效。
  • 精修不同来源声音之间的平衡。
  • 补记素材来源、录音位置和版本变化。
  • 通过具体实验确定音乐与视觉的关系。

创作体会

这次创作让我更具体地理解了“组织声音”意味着什么。

有些材料来自生成，有些来自录音，有些通过剪辑和重新排列才找到作用。我在制作中的工作，是不断判断它们之间的关系，并把这些判断落实到作品里。

先完成一个能够完整试听的版本，也让下一步的问题变得清楚。这个阶段版本已经能够帮助我听见方向，并继续向前修改。
